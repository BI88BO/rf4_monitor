# 浮窗玻璃拟态观感改造设计

日期：2026-08-18
状态：已批准

## 背景

当前 RF4 来鱼浮窗（`rf4_overlay.pyw`）是单个 `tk.Label`：
深色底 `#101418` + 琥珀字 `#ffd166`，微软雅黑 13 加粗，无圆角无边框，
整窗换色仅用于"鱼力竭"变红。用户希望美化浮窗观感。

## 目标

- 半透明玻璃拟态风格（深色青黑玻璃底 + 青绿文字）
- Canvas 圆角卡片，含高光描边与顶部 HUD 装饰线
- 使用系统字体"三极芯片体 超粗"（缺失回退微软雅黑）
- **只改观感**，不引入多色渲染、磨砂模糊、动画，不加配置项

## 设计方案

### 渲染结构

将单个 `tk.Label` 替换为 `tk.Canvas`（`rf4_overlay.pyw`）：

```
Canvas（WINDOW_WIDTH x 自适应高）
├── 圆角背景矩形：青黑玻璃底 #0F1916（模拟半透明感）
├── 内侧描边：1px 高光 #1D4D3F（玻璃边缘）
├── 顶部装饰线：2px 青色 #2EE6A8（HUD 强调条）
└── 文本 create_text 左对齐（wraplength 同现宽度）
```

### 样式参数

扩展 `_STYLE_PARAMS`：

| 项 | 值 |
|---|---|
| 背景 | `#0F1916` |
| 圆角半径 | 12px |
| 描边 | `#1D4D3F`（1px） |
| 装饰线 | `#2EE6A8`（2px） |
| 主文字（鱼名/事件） | `#4FF2C8` |
| 遥测/待机文字 | `#8FD6C2` |
| 力竭变红 | `#FF5252`（保留现有触发逻辑） |
| 字体 | `三极芯片体 超粗` 13 号，缺失回退微软雅黑 |
| 透明键 | `#0000FF` 哨兵色，四角圆角区域填充实现真圆角 |

### 几何与布局

- 窗口宽 320 不变
- 高度按内容自适应；`_content_height` 改为用 Canvas 字体度量重算
- 圆角 12px，padding 16 保持现有节奏
- 拖动、位置记忆、配置热载（`apply_style`/`_poll_config`）、
  `-transparentcolor` 机制全部保留

### 数据流与错误处理

- `_rows`/`_telemetry_rows` 内容拼接逻辑不变
- `label.config(text=...)` 全部改为 Canvas 重绘 `_draw()`
- `_handle_datagram` 事件分发不变
- `apply_style` 改为按样式重绘 Canvas 各图形项与文本颜色
- 字体缺失回退：运行时用 `tkfont.families()` 检查，不在则用微软雅黑

### 测试

- 更新/新增 `tests/test_overlay.py`：
  - 字体回退（无三极芯片体时用微软雅黑）
  - 圆角尺寸（背景矩形坐标符合 12px 半径）
  - 样式切换（dark/transparent 重绘）
  - 力竭变红（体力 ≤ 0 时文本为 `#FF5252`）
  - 透明键设置（`-transparentcolor` 为哨兵色）
- 人工验证：运行浮窗，确认玻璃底/圆角/拖动手感/事件弹出

## 范围外

- 多色分段渲染（Text/Canvas 分段着色）
- 真半透明/磨砂模糊（Windows `-transparentcolor` 仅支持二值透明）
- 动画、渐入渐出
- 新增配置项
